### // 03 &bull; PRODUCTION SYSTEMS &amp; FEATURED WORK

#### [vector-guardrail](https://github.com/DileepWick/vector-guardrail)
> Modular, production-grade AI security gateway &amp; REST API for intercepting LLM prompt injection attacks using vector embeddings (Google Gemini &amp; SentenceTransformers), ChromaDB HNSW indexing, and circuit-breaker resilience.
* **Stack**: Python, Google Gemini, ChromaDB, SentenceTransformers, REST API
* **Architecture**: Vector embeddings similarity search &bull; Out-Of-Distribution (OOD) clustering &bull; Circuit-breaker failover

#### [token-lab](https://github.com/DileepWick/token-lab)
> Interactive LLM Token Engineering Laboratory &amp; Real Byte-Pair Encoding (BPE) Studio. Inspect real tokens for GPT-4o, Llama 3, and Qwen 2.5, benchmark schema compression, and calculate prompt cost/latency ROI.
* **Stack**: JavaScript, Node.js, Tiktoken, BPE Tokenizers
* **Architecture**: In-browser token visualization &bull; Compression ratio calculators &bull; Multi-model tokenizer comparison

#### [vector-doc-engine](https://github.com/DileepWick/vector-doc-engine)
> Production-resilient TypeScript engine for PDF text chunking, Gemini vector embeddings, and ChromaDB HNSW semantic search.
* **Stack**: TypeScript, ChromaDB, Google Gemini API, PDF Processing
* **Architecture**: Deterministic chunking &bull; Vector search pipeline &bull; Fault-tolerant embeddings generation

#### [zero-shot-vector-classification-eval](https://github.com/DileepWick/zero-shot-vector-classification-eval)
> Zero-latency TypeScript classification engine using Google Gemini vector embeddings, in-memory cosine distance matrix, L1 LRU caching, and OOD guardrails.
* **Stack**: TypeScript, Google Gemini, LRU Cache
* **Architecture**: In-memory matrix computation &bull; L1 cache layer &bull; Zero-shot semantic clustering

#### [Official-Taiho-Toyota-Bearing-Catalogue-MCP-Server](https://github.com/DileepWick/Official-Taiho-Toyota-Bearing-Catalogue-MCP-Server)
> Model Context Protocol (MCP) server providing authoritative engineering and catalogue specifications for Toyota engine bearings.
* **Stack**: Model Context Protocol (MCP), TypeScript, JSON Schema
* **Architecture**: Standardized AI tool protocol &bull; Fast structured catalogue lookup
